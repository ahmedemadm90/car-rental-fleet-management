# منصة تأجير السيارات وإدارة الأساطيل (Car Rental & Fleet Management System)

مشروع متكامل يربط بين العملاء ومحال تأجير السيارات (للسفر، الرحلات، وحفلات الزفاف)، ويتيح لأصحاب المحال تتبع المصروفات الدورية، الصيانات، ومواعيد تغيير الزيوت لضمان ربحية الأسطول.

## هيكل المستودع (Repository Structure)
يحتوي المستودع على مجلدين رئيسيين:
1. **`backend-laravel/`**: الواجهة البرمجية الخلفية وقاعدة البيانات بنظام Laravel 11.
2. **`frontend-flutter/`**: تطبيق الهاتف المحمول للعملاء والمحال بـ Flutter (دعم اللغة العربية).

---

## 1. الواجهة الخلفية (Laravel Backend)
- **المميزات:**
  - إدارة السيارات (إضافة، تعديل، حذف، حالة السيارة: متاح/مؤجر/صيانة).
  - إدارة الحجوزات (سفر، زفاف، يومي).
  - إدارة المصروفات والصيانة (متابعة الزيوت، قطع الغيار، التكاليف).
- **التشغيل:**
  ```bash
  cd backend-laravel
  composer install
  cp .env.example .env
  php artisan key:generate
  php artisan migrate
  php artisan serve
  ```

---

## 2. تطبيق الهاتف (Flutter Frontend)
- **المميزات:**
  - عرض قائمة السيارات المتاحة للزفاف والسفر.
  - شاشة مخصصة لأصحاب المحال لتسجيل الصيانات والمصروفات اليومية والدورية.
  - واجهة مستخدم باللغة العربية بالكامل (RTL).
- **التشغيل:**
  ```bash
  cd frontend-flutter
  flutter pub get
  flutter run
  ```
